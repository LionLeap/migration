# migration

我写下来，不是因为我已经明白了这些事情。恰恰相反，是因为我还没有明白。写作不是结论，而是思考本身。它给了我一个地方，让我一边生活，一边观察；一边困惑，一边整理；一边抱怨，一边慢慢接受。我不知道这些经历最后会通向哪里，也不知道它们是不是值得。但只要把它们写下来，那些原本只能默默承受的日子，就开始有了形状。有了形状，就有了意义；有了意义，痛苦就不再占据全部。

这些年，我不是在体验另一种生活。因为对很多人来说，这从来都不是另一种生活，这就是生活。我只是因为人生的转弯，终于有机会站到了这一边。站得越久，越觉得应该少一点抱怨，多一点谦卑。我不知道以后这些技能会不会再派上用场，也不知道为什么我总想把它们写下来。我只是隐约觉得，这些看似微不足道的日常，也值得有人认真记录。
