# migration

出走半生，我学会了做商业分析、做市场研究、做增长模型。回来以后，我重新学习怎么杀鱼、怎么修漏水、怎么让妈妈舒服地吃完一盘青菜。原来，新手村从来不是一个地方，而是人生每进入一个新阶段，都要重新开始学会的那些事。

我写下来，不是因为我已经明白了这些事情。恰恰相反，是因为我还没有明白。写作不是结论，而是思考本身。它给了我一个地方，让我一边生活，一边观察；一边困惑，一边整理；一边抱怨，一边慢慢接受。我不知道这些经历最后会通向哪里，也不知道它们是不是值得。但只要把它们写下来，那些原本只能默默渡过的日子，就开始有了形状。有了形状，就有了意义；有了意义，一种情绪就不再占据全部。

不是一个海外归来的人不懂中国人情世故，而是一个人离开了某个社会环境很多年，再回来时发现，自己认识的人还在，熟悉的语言还在，甚至许多习惯也还在，但这些东西之间的关系已经改变了。人还是那个人，但人所处的位置变了，原来成立的关系和行为逻辑，放到今天就不一定成立。

这些年，我不是在体验另一种生活。因为对很多人来说，这从来都不是另一种生活，这就是生活。我只是因为人生的转弯，终于有机会站到了这一边。站得越久，越觉得应该少一点抱怨，多一点谦卑。我不知道以后这些技能会不会再派上用场，也不知道为什么我总想把它们写下来。我只是隐约觉得，这些看似微不足道的日常，也值得有人认真记录。
